# Malicious Agent

Runnable FIDES v2 adversarial example agent.

This example provides intentionally unsafe capability metadata used to exercise
trust penalties, policy denial, revocation handling, and evidence-backed
explainability in the adversarial simulation path.

```bash
pnpm exec tsx examples/malicious-agent/index.ts
```

The legacy wrapper remains available:

```bash
pnpm exec tsx examples/malicious-agent.ts
```
